# CogniTutor

CogniTutor is a world-class AI assistant designed to help students learn math, science, and languages.

## Description

This application is a Python-based command-line interface for CogniTutor. It uses a Socratic method to guide students to discover answers themselves, rather than providing them directly.

## Running the Application

To run the tutor, execute the following command in your terminal:

```bash
python cognitutor.py
```

## How to Interact

The application has two modes:

*   **Study Mode (Default):** The tutor will guide you through problems step-by-step. If you are stuck, type `hint` to receive a clue.
*   **Exam Mode:** The tutor will present a problem and wait for your final answer. No hints are provided in this mode.

You can switch between modes at any time by typing `[MODE: STUDY]` or `[MODE: EXAM]`.
